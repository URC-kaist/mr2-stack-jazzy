Dashboard type correction
-------------------------
The baseline dashboard/src/lib/rosMessages.ts declared nine type aliases twice,
causing 18 TS2300 diagnostics. This change removes the repeated aliases while
retaining every distinct type name and field. CarriageMotorTelemetryMsg keeps
its optional stamp field, and the unique PumpRequest declaration remains.
No ROS message definition or runtime message handling is changed.

Before this correction, web-enabled installer checks returned nonzero at the
dashboard typecheck. The correction resolves that failure; typecheck remains
mandatory and no acceptance check is bypassed. Both typecheck and production
build are checked by the final full setup/check commands.

Reproduction
------------
Clone with --recurse-submodules. On the appropriate Ubuntu 24.04 host:
  bash scripts/setup_dev.bash --prefix "$HOME/.local/share/mr2-jazzy"
  bash scripts/setup_base.bash --prefix "$HOME/.local/share/mr2-jazzy"
  bash scripts/setup_rover.bash --prefix "$HOME/.local/share/mr2-jazzy"
For Nano validation, add --allow-nano-validation to the rover command.
Add --with-rover-direct to exercise the rover's local gateway/dashboard.
Append --check for subsequent checks without package installation.

OS installation and JetPack flashing are prerequisites. Validation uses a new
prefix, venv, toolchain, message build/install tree and node_modules under a
fresh clone. Hash-checked download archives may be copied from existing
caches. Existing venvs, node_modules and compiled workspaces are not copied.
The hosts already have apt packages installed; this is not a bare-OS first
installation test. Nano results do not certify NX-specific hardware.

Use the generated perception-python wrapper (or source perception.bash) for
perception execution. On rover the wrapper selects system CUDA/cuDNN/nvJPEG;
merely activating the raw venv does not apply that SDK selection.
The accepted PyTorch sm_87 warning remains documented. No warning suppression,
wheel modification, TensorRT-default switch or motor actuation is performed.
